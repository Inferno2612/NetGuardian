Режимы блокировки

Простая — NetGuardian каждую секунду проверяет запущенные программы и закрывает совпавшие вместе со всеми их процессами. Права администратора не нужны, но приложение может на мгновение мигнуть на экране.

Надёжная (IFEO) — Windows вообще не даёт приложению запуститься. Включается один раз с правами администратора. Для работы при включённом VPN NetGuardian должен быть запущен от администратора: он временно снимает перехват, пока VPN подключён.
