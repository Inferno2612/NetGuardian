# NetGuardian

Десктопное приложение для Windows, которое следит за VPN и **не даёт выбранным программам работать без него**. Если VPN выключен, такие приложения закрываются, а на экране появляется уведомление с просьбой включить VPN.

Работает с любыми VPN, которые создают виртуальный сетевой адаптер: Hiddify (режим TUN), Amnezia (AmneziaWG), WireGuard, OpenVPN/TAP и другими. Не работает с VPN в режиме системного прокси: у него нет адаптера, по которому можно определить подключение.

Приложение написано на Rust + Tauri 2.

## Возможности

- **Блокировка приложений без VPN.** Список программ задаётся вручную. Электрон-приложения (Discord, Claude, Slack и т. п.) закрываются вместе со всеми дочерними процессами.
- **Два режима блокировки.**
  - *Простая* — фоновая проверка раз в секунду. Права администратора не нужны, но программа может на мгновение появиться на экране.
  - *Надёжная (IFEO)* — Windows вообще не даёт программе запуститься. Нужны права администратора.
- **Статус VPN** на главном экране и в нижней панели.
- **Трафик в реальном времени** по выбранному сетевому адаптеру, объём за последний час и с момента загрузки ПК.
- **«Как меня видят»** — внешний IP-адрес, страна, провайдер, часовой пояс.
- **Мониторинг сайтов** — проверка доступности раз в 5 минут, число сайтов не ограничено.
- Автозапуск вместе с Windows.
- Стеклянный тёмный интерфейс (Mica/Acrylic).

## Установка

1. Откройте [Releases](../../releases) и скачайте `NetGuardian_*_x64-setup.exe`.
2. Запустите установщик.

**Предупреждение SmartScreen.** Установщик не подписан сертификатом издателя, поэтому Windows покажет «Неизвестный издатель». Нажмите «Подробнее» → «Выполнить в любом случае». Часть антивирусов может насторожиться: программа завершает процессы и (в надёжном режиме) пишет в реестр. Исходный код открыт, его можно проверить и собрать самому.

Требуется Windows 10/11 и WebView2 (в Windows 11 уже встроен, в Windows 10 установщик поставит сам).

## Как пользоваться

1. Откройте вкладку **«Блокировка»**, введите имя исполняемого файла (например, `discord.exe`) и нажмите «Добавить». Имя файла видно в Диспетчере задач на вкладке «Подробности».
2. Оставьте включённой «Простую» блокировку. Теперь без VPN программа будет закрываться.
3. Для **«Надёжной»** блокировки перезапустите NetGuardian от имени администратора и включите переключатель в столбце «Надёжная».

Настройки хранятся в `%APPDATA%\NetGuardian\config.json`, журнал блокировок — в `%APPDATA%\NetGuardian\blocker.log`.

### Рекомендации

- Запускайте NetGuardian **от имени администратора**: иначе нельзя закрыть процессы, запущенные с повышенными правами, и недоступен надёжный режим.
- Автозапуск и надёжный режим привязаны к пути установленного файла. Включайте их из установленной копии, а не из папки сборки.
- В надёжном режиме NetGuardian временно снимает перехват, пока VPN подключён: многопроцессные приложения на Chromium иначе не запускаются. Для этого он должен работать (от администратора).
- Надёжный режим меняет системный реестр (`Image File Execution Options`). Если что-то пошло не так, удалите подраздел нужного `.exe` в `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options` или снимите галочку в программе.

## Как определяется VPN

NetGuardian ищет активный виртуальный адаптер по подстрокам в имени и описании: `wintun`, `wireguard`, `amneziawg`, `hiddify`, `sing-box`, `tun`, `tap`. Встроенные адаптеры Windows (Teredo, ISATAP, 6to4, Loopback, Bluetooth) исключаются.

Если ваш VPN определяется неверно, откройте **«Настройки → Сетевые адаптеры»**, посмотрите настоящее имя адаптера и добавьте подходящую подстроку в `vpn_adapter_hints` в `config.json`.

Трафик считается по каждому интерфейсу отдельно, чтобы не удваивать счётчик, когда один и тот же поток виден и на VPN-адаптере, и на физическом.

## Сборка из исходников

Нужны [Rust](https://rustup.rs), [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (компонент «Разработка классических приложений на C++») и Tauri CLI:

```powershell
cargo install tauri-cli --version "^2"
```

Запуск в режиме разработки:

```powershell
cargo tauri dev
```

Релизная сборка:

```powershell
cargo tauri build
```

Установщик появится в `target\release\bundle\nsis\`.

## Структура проекта

```
core/           общая логика: VPN, трафик, конфиг, IFEO, автозапуск, проверка сайтов
src-tauri/      приложение (Tauri): команды, процесс-вотчер, окно-уведомление
ui/             интерфейс (HTML/CSS/JS без сборщика)
native-host/    нативный хост для браузерного расширения
browser-extension/  расширение браузера (блокировка ссылок)
```
